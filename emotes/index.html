Tips for emotes that read well

Start big. Draw or export at 500 pixels or more and let this shrink it. Making a small image bigger always looks blurry.

Think 28 pixels. That's how big an emote is in chat. Thick outlines, one clear expression or object and few small details survive; fine text and thin lines don't.

Use a see-through background. Emotes sit on dark and light chat themes, so check both previews above.

Animated GIFs come out animated for emotes and as a still first frame for badges. If a size goes over its limit, the tool cuts colours first, then frames, until it fits; Twitch also gets cut to 60 frames. GIFs have no soft edges, so outlines on see-through backgrounds look best kept bold. Short loops with fewer colours give the cleanest results.
