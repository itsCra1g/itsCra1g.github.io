Make a Discord webhook

A webhook is a link that lets Streamer.bot post into one of your channels. You need to be able to manage the server.

  1. In Discord, open Server Settings → Integrations → Webhooks and press New Webhook.
  2. Give it a name and picture (that's who the post comes from), and pick the channel to post in, like #going-live.
  3. Press Copy Webhook URL and paste it below.
Keep the webhook private. Anyone with it can post in that channel. This page doesn't store it or send it anywhere except Discord when you press Send test post.

If something's not right

    

      
What you seeWhat to do

      
The test post failsCopy the webhook URL again from Discord. If the webhook was deleted, make a new one.

      
Nothing posts when I go liveCheck the action is enabled and has the Stream Online triggers. Streamer.bot's log (in its logs folder) shows a "Discord Live" line if Discord refused the post.

      
The role ping doesn't notifyCheck the role ID, and that the role is allowed to be mentioned (Server Settings → Roles → the role → Allow anyone to @mention).

      
The preview image is blankTwitch takes a minute or so to make it. Raise the wait to 90 or 120 seconds.

      
The title says "YourName is live"Your Streamer.bot version couldn't fetch the Twitch title, so it used that instead. Put your own words in Card title.
