4

Latest follower and sub (optional)

With Streamer.bot (1.0 or later) running and connected to Twitch, Kick or both, the scenes show your latest follower and latest sub (gifts count, shown as the gifter). Turn on its WebSocket server: Servers/Clients → WebSocket Server, tick Auto Start, press Start Server. There's no action to add.

Streamer.bot connection (only if you changed it)

No Streamer.bot? The scenes still work; those spots just stay hidden.

5

Add them to OBS

One link per scene, with everything above built in:

Gameplay
Just Chatting
Waiting
  1. In each scene, press + under Sources and pick Browser. Paste that scene's link and set the size to 1920 × 1080.
  2. Put the browser source at the top of the scene's Sources list.
  3. Put your camera (and game capture) below it, then drag and size them so they show through the windows. Holding Alt while dragging an edge crops a source in OBS.
  4. For chat, add Combined Chat (or any chat overlay) above the browser source and fit it inside the chat panel.
