One poll for Twitch and Kick chat.

Twitch's own polls leave your Kick viewers out. Start a poll with one command and everyone votes by typing a number in either chat, with live bars on stream showing Twitch and Kick votes side by side.

New to Streamer.bot? Set it up first with the Streamer.bot Starter guide (about 20 minutes).

1

Add it to Streamer.bot

Polls run in Streamer.bot (1.0 or later), connected to Twitch, Kick or both, so votes count and results post to chat even when the overlay isn't on screen.

  1. In Streamer.bot, press Import (top of the window), paste this into Import String and press Import. It adds two actions, Poll and Poll Timer, and the poll commands.
  2. Open the Commands tab and switch on the imported commands (right-click each one and tick Enabled). Commands always arrive switched off.
  3. For the overlay, open Servers/Clients → WebSocket Server, tick Auto Start and press Start Server. Already done this for another overlay here? Then skip it.
Rather make it yourself?
  1. Add an action called exactly Poll. Add a sub-action Core → C# → Execute C# Code, paste in this code, then press Compile and Save and Compile.
  2. Give Poll these triggers: Twitch → Chat → Chat Message, Kick → Chat → Chat Message, and a Core → Commands → Command Triggered trigger for each of these commands (make them in the Commands tab, for Twitch and Kick): !poll, !endpoll, !cancelpoll, !pollresults, !vote.
  3. Add a second action called exactly Poll Timer with no triggers, and paste this code into an Execute C# Code sub-action the same way.

Want different wording, a longer default time or anyone to be able to start polls? Change the lines at the top of the Poll code.

2

Run a poll

Start one from either chat. Separate the question and the options with |:

!poll Best map? | Rebirth | Verdansk | Area 99

Add a time first if you want something other than a minute: !poll 2m Best map? | Rebirth | Verdansk or !poll 30 Quick one? | Yes | No.

Streamer.bot posts the poll in both chats, viewers vote by typing 1, 2, 3 (or the option's name), and when time's up it posts the winner to both chats.

CommandWhoWhat it does
!pollYou and modsStarts a poll. Up to 6 options, 10 seconds to an hour.
!endpollYou and modsCloses it early and posts the result.
!cancelpollYou and modsThrows it away without a result.
!pollresultsAnyoneThe votes so far, or the last result.
!vote 2AnyoneAnother way to vote (just typing 2 works too).

Each viewer gets one vote per platform, and can change it by typing another number. The result goes out as a Twitch announcement if your bot account is a mod; Kick gets a normal message.

4

Add it to OBS

Your poll link, with your style built in:

  1. In OBS, press + under Sources and pick Browser.
  2. Paste the link into URL and set the size to 800 × 600. Resize it in OBS to make it bigger or smaller.
  3. Press OK and start a test poll from chat to see it.
?

If something's not right

What you seeWhat to do
Nothing happens when I type !pollSwitch the commands on in Streamer.bot's Commands tab (they import switched off), and check you're a mod or the broadcaster.
The poll never closesCheck the Poll Timer action is there and named exactly that. You can always close it with !endpoll.
Chat works but the overlay shows nothingStart Streamer.bot's WebSocket server (step 1). If you changed the address, port or set a password, enter them in step 3 and copy the link again.
Only one platform's votes countCheck Streamer.bot is connected to both Twitch and Kick, and the Poll action has both Chat Message triggers.
