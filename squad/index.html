1

Connect it to chat

The overlay reads !join straight from Streamer.bot (1.0 or later), connected to Twitch, Kick or both. A small action posts the picks in chat and links the dock to the overlay.

  1. In Streamer.bot, press Import (top of the window), paste this into Import String and press Import. It adds one action, Squad Picker.
  2. Open Servers/Clients → WebSocket Server, tick Auto Start and press Start Server. Already done this for another overlay here? Then skip it.
Rather make it yourself?
  1. In Streamer.bot's Actions tab, right-click, choose Add and name it exactly Squad Picker. It needs no triggers.
  2. Right-click in Sub-Actions, choose Core → C# → Execute C# Code, paste this over what's there, press Compile, then Save and Compile.
  3. Open Servers/Clients → WebSocket Server, tick Auto Start and press Start Server.

No Streamer.bot needed: the overlay reads your Twitch chat directly. Type your Twitch channel name:

Post the picks in chat (optional)

To have the overlay post who got picked, log in with the Twitch account that streams. It asks only to send chat messages as you.

Your login is built into the OBS link in step 4, so don't share that link or show it on stream. Twitch logins last about two months; when it runs out, log in again here and paste the new link into OBS.
2

Run it

  1. Open it with the dock's Open button, or type !squad open in chat.
  2. Viewers type !join with their in-game ID, like !join CRA1G#4815162. Typing it again updates their ID.
  3. Press Pick on the dock (or type !squad pick). The overlay spins and lands on each player, then posts the squad in chat.
  4. Someone not turned up? Press Swap next to their name to pick someone else in their place.
CommandWhoWhat it does
!join IDAnyoneJoins the list, with their in-game ID if they type one. Only while it's open.
!leaveAnyoneTakes them off the list.
!squad open / !squad closeYou and modsOpens or closes joining. Closing keeps the list.
!squad pick / !squad pick 2You and modsPicks a new squad (the dock's size, or the number you type).
!squad swap nameYou and modsSwaps one player for someone new.
!squad remove nameYou and modsTakes someone off the list.
!squad clearYou and modsEmpties the list and the squad.
!squad resetYou and modsClears everything, including who has already played.

The overlay does the picking, so it needs to be open in OBS (it can be hidden in a scene you're not on, as long as Shutdown source when not visible is unticked). The list is remembered if OBS restarts.

4

Add it to OBS

The overlay

  1. In OBS, press + under Sources and pick Browser.
  2. Paste the link into URL and set the size to 640 × 760. Resize it in OBS to make it bigger or smaller.
  3. Leave Shutdown source when not visible unticked. Using it in more than one scene? Add it to the others with Paste (Reference), so there's only one copy.

The dock (your controls)

  1. In OBS, open Docks → Custom Browser Docks.
  2. Name it Squad Picker, paste the link into URL and press Apply.
  3. It shows who's joined and their IDs, with buttons to open, pick, swap and remove. Click an ID to copy it.

No dock? Everything also works from chat with the !squad commands.
