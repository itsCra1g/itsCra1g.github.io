1

Turn on Streamer.bot's WebSocket server

The feed comes straight from Streamer.bot (1.0 or later), connected to Twitch, Kick or both. There's no action or code to add.

  1. In Streamer.bot, open Servers/Clients → WebSocket Server.
  2. Tick Auto Start and press Start Server. Leave it on 127.0.0.1 port 8080 unless you've changed it.

Already set up for Alerts, Combined Chat, Sub Goal or Credits? Then you're done.

2

Pick what shows and the wording

Untick any you don't want. Each line shows the viewer's name, then your wording: use {amount} for the number of subs, bits, Kicks or raiders, {months} for months subscribed and {to} for who got a gifted sub.

Gift bombs show as one line, not one for every sub in them.

4

Add it to OBS

Your feed link, with your choices built in:

  1. In OBS, press + under Sources and pick Browser.
  2. Paste the link into URL and set the size: 500 × 400 for the list, or 1920 × 56 for the ticker.
  3. Press OK and drag it where you want it. The feed remembers its list, so it's still there if OBS restarts.

Changed something? Copy the new link and paste it over the old one.
