New to Streamer.bot? Set it up first with the Streamer.bot Starter guide (about 20 minutes).

1

Turn on Streamer.bot's WebSocket server

The chat comes straight from Streamer.bot (1.0 or later), connected to Twitch, Kick or both. There's no action or code to add.

  1. In Streamer.bot, open Servers/Clients → WebSocket Server.
  2. Tick Auto Start and press Start Server. Leave it on 127.0.0.1 port 8080 unless you've changed it.

That's it. Already set up for Sub Goal or Credits? Then you're done.

3

Add it to OBS

Your chat link, with your style built in:

  1. In OBS, press + under Sources and pick Browser.
  2. Paste the link into URL. A good size is 450 × 800; make it wider or taller to fit your layout. Text size stays the same, so a bigger source just shows more messages.
  3. Press OK and say something in chat. Messages appear at the bottom and move up.

Changed the style? Copy the new link and paste it over the old one.
