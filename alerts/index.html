New to Streamer.bot? Set it up first with the Streamer.bot Starter guide (about 20 minutes).

1

Connect your alerts

Alerts come straight from Streamer.bot (1.0 or later), connected to Twitch, Kick or both. There's no action or code to add.

  1. In Streamer.bot, open Servers/Clients → WebSocket Server.
  2. Tick Auto Start and press Start Server. Leave it on 127.0.0.1 port 8080 unless you've changed it.

Already set up for Combined Chat, Sub Goal or Credits? Then you're done.

Only stream on Twitch? Log in with Twitch and the alerts come straight from Twitch, with nothing else to install.

This lets the overlay read your follows, subs, cheers and raids. It can't post, change or see anything else. Twitch logins like this last about 60 days: when it runs out, the overlay tells you, so come back here, log in again and paste the new link into OBS.

Your OBS link now has your Twitch login in it. Keep it private: don't share it or show it on stream.
2

Pick your alerts and wording

Untick any you don't want. The line above the viewer's name is yours to change: use {amount} for the number of subs, bits, Kicks or raiders, {months} for months subscribed and {to} for who got a gifted sub.

Gift bombs show as one alert, not one for every sub in them.

Your own image or GIF instead of the icon

Paste a link to a .gif, .png or .webp for any alert type. Leave it empty to keep the normal icon. Use a link that starts with https and won't expire, such as one from Imgur, Giphy or your own site. Discord links stop working after a while.

Sounds
My sound files: Streamer.bot plays them from your PC as each alert appears.
  1. Put your sounds in one folder and name them after the alert: follow, sub, resub, gift, bomb, cheer, kicks, raid (.mp3 or .wav). Add all.mp3 to play for any alert without its own sound.
  2. In Streamer.bot, press Import (top of the window), paste this into Import String and press Import. It adds an action called Alerts Sound with no triggers.
    Rather make it yourself?

    Right-click in Actions, choose Add and name it exactly Alerts Sound (no triggers). Right-click in its sub-actions, choose Core → C# → Execute C# Code, paste this code over what's there, then press Compile and Save and Compile.

  3. Paste the folder's location here. In File Explorer, click the bar at the top of the folder and copy it, e.g. C:\Stream\Alert sounds.
The preview here plays the built-in chimes. If Streamer.bot can't find the Alerts Sound action, the overlay plays the chime instead.

4

Add it to OBS

Your alerts link, with your choices built in:

  1. In OBS, press + under Sources and pick Browser.
  2. Paste the link into URL and set the size to 900 × 400. Drag it where you want alerts to appear, and resize it to make the alerts bigger or smaller (or use the Size slider).
  3. To hear the sounds on stream, tick Control audio via OBS in the same window, then press OK.

Changed something? Copy the new link and paste it over the old one.

If something's not right

What you seeWhat to do
No alerts showCheck Streamer.bot is running, its WebSocket server is started, and it's connected to Twitch or Kick. If you changed the address, port or set a password, enter them in step 3 and copy the link again.
Twitch only: "Twitch login expired" showsCome back to this page, press Log in with Twitch and paste the new link into OBS.
Only one platform alertsCheck Streamer.bot is connected to both Twitch and Kick (Platforms tab).
No sound on streamTick Control audio via OBS on the browser source and check it isn't muted in the audio mixer.
My sound files don't playCheck the action is named exactly Alerts Sound and compiled, the folder location is right (copy the OBS link again after changing it), and the files are named like raid.mp3. You hear the chime if the action can't be found; nothing plays if the folder or file is missing, and Streamer.bot's log says which.
Alerts double up with another toolTurn that alert type off here, or in the other tool, so only one shows it.
