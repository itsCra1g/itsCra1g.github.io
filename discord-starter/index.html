3

Setting it up, in order

  1. Create the server: the + at the bottom of your server list → Create My Own → For a club or community.
  2. Make the roles first (Server Settings → Roles), in the order shown in your plan: higher roles can manage lower ones. Give Mods the moderation permissions and nobody but you Administrator.
  3. Make the categories and channels. Right-click a category → Edit Category → Permissions to make a whole area read-only or role-only, and let channels follow it ("sync").
  4. Turn on Community (Server Settings → Enable Community). It unlocks Onboarding, a rules screen, announcement channels and server insights. Community requires a verification level and the explicit media filter, which you want anyway.
  5. Set up Onboarding (Server Settings → Onboarding): choose the default channels new members see, and add a question like "Want a ping when I go live?" that gives the Live pings role.
  6. Safety (Server Settings → Safety Setup):
    • Verification level Medium (registered on Discord for 5+ minutes) or High if you get raids.
    • Explicit image filter on for all members.
    • AutoMod on: block spam, mention spam and a keyword list (slurs, scam phrases like "free nitro").
    • Require two-factor authentication for moderator actions.
    • Stop @everyone pings for everyone except you and mods.
  7. Paste in the messages above: welcome, rules (also add them to the rules screen), and a pinned role-pick message if you're not using Onboarding questions.
  8. Add live posts and sub roles (below), then do a test with a friend's account before you share the invite.
  9. Make an invite that never expires (Invite People → Edit invite link → Expire: Never) and put it in your panels, !discord command and socials.

5

Sub and supporter roles

Twitch (built in)

  1. You need to be a Twitch Affiliate or Partner.
  2. In Discord: User Settings → Connections → connect Twitch.
  3. Server Settings → Integrations → Twitch → follow the steps. Discord creates a Twitch Subscriber role plus one for each tier, and keeps them in sync.
  4. Set the grace period (how long someone keeps the role after their sub ends), then rename and colour the roles to suit your server.
  5. Viewers connect their own Twitch account in Discord to get the role.

Kick

Kick doesn't have a built-in Discord connection yet. Options: a third-party bot that links Kick subs (read its reviews and permissions first), or a simple Kick Sub role your mods give out when someone shows their sub badge.

YouTube

If your channel has memberships, check Server Settings → Integrations for a YouTube option to sync member roles.

6

Keep it alive

  • Be there yourself. Reply to people, especially early on. A server the streamer never visits goes quiet fast.
  • Post your schedule weekly (the Schedule Maker gives you an image and text) and pin it.
  • Give a reason to visit between streams: clips, polls, behind-the-scenes, a weekly question, game nights with the community.
  • Talk about it on stream, and add a !discord command and a Discord panel (Panel Maker).
  • Pick mods you trust, write down what's allowed, and back them up. Never give anyone a role with Administrator unless you'd trust them with the whole server.
  • Watch for scams: fake "free Nitro" links, fake brand deals and people pretending to be you. Tell members you'll never DM them first asking for anything.
