Follower, bits and Kicks goals.

Up to three goal bars in one overlay, counting Twitch and Kick together: followers, bits, Kicks, bits and Kicks combined. Pairs with Sub Goal.

Twitch + KickUp to 3 barsBits + Kicks combinedFix counts from chatNo Streamer.bot action needed

New to Streamer.bot? Set it up first with the Streamer.bot Starter guide (about 20 minutes).

1

Turn on Streamer.bot's WebSocket server

The bars count events straight from Streamer.bot (1.0 or later), connected to Twitch, Kick or both. There's no action or code to add.

  1. In Streamer.bot, open Servers/Clients → WebSocket Server.
  2. Tick Auto Start and press Start Server. Leave it on 127.0.0.1 port 8080 unless you've changed it.

Already set up for Alerts, Activity Feed or Combined Chat? Then you're done.

2

Set your goals

Start from is where the bar begins. For a total follower goal, put your follower count now (say 1,180 towards 1,500); for "new this stream", leave it at 0.

Bits + Kicks counts 1 bit and 1 Kick the same, as both are worth about a cent.

4

Add it to OBS

Your goal bars link, with your goals built in:

  1. In OBS, press + under Sources and pick Browser.
  2. Paste the link into URL and set the size to 760 × 340. Resize it in OBS to make it bigger or smaller.
  3. Want the bars in more than one scene? Add the source once, then use Paste (Reference) in the other scenes, so they share one count.

Changed a goal? Copy the new link and paste it over the old one. Changing a start from number restarts that bar from it.

5

Fix a count from chat

Missed something, or want to top a bar up? You and your mods can set it from Twitch or Kick chat. Bars are numbered top to bottom.

TypeWhat it does
!goalset 1 150Sets bar 1 to 150.
!goaladd 2 500Adds 500 to bar 2 (use a minus number to take some off).
!goalreset 1Puts bar 1 back to its start from number.

These work without setting up any commands in Streamer.bot: the overlay reads them from chat. They don't reply in chat; the bar just changes.

?

If something's not right

What you seeWhat to do
The bars don't moveCheck Streamer.bot is running, its WebSocket server is started, and it's connected to Twitch or Kick. If you changed the address, port or set a password, enter them in step 3 and copy the link again.
Things count twiceYou probably have two separate copies of the source. Delete one and use Paste (Reference) instead.
A count is wrongUse !goalset from chat (step 5).
Kicks don't countKick's gift events are new in Streamer.bot; update Streamer.bot to the latest version.
