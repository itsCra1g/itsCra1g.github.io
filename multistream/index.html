Go live on Twitch, Kick, YouTube and TikTok at once.

Multistreaming puts you in front of more people from one stream. This guide covers the ways to do it from OBS, whether your internet can handle it, each platform's rules (some of which cost money if you get them wrong), the setup for each one, and fixes when it goes wrong.

The usual setup: keep Twitch as OBS's main stream (Twitch's Enhanced Broadcasting and Dual Format only work on that main connection), then add the other platforms as plugin outputs. If your upload can't take it, switch to a relay.

3

Each platform's rules

Checked 17 November 2026, and they do change. Have a quick look at each platform's own rules before you start, especially if you're a Twitch Partner, a Kick Partner, or have any kind of contract.

Twitch
  • Multistreaming is allowed for everyone.
  • Twitch must look at least as good as anywhere else. Don't send YouTube or Kick a higher quality than Twitch. Sharing one encoder for every landscape output keeps this simple.
  • Don't send Twitch viewers away to your other live streams: no "come watch on Kick/YouTube" links, banners, chat commands or QR codes while you're live. Saying you also stream elsewhere is fine. A socials rotation that shows your Kick or YouTube while you're live there is a grey area, so consider leaving those out.
  • Combined chat on stream: Twitch's written rules still say not to show merged chat from other platforms on the Twitch stream. Twitch said early in 2026 it would stop enforcing that, but the rule hasn't been removed. Showing it is your call; Twitch-only chat on screen is the zero-risk option.
Kick
  • Kick Partners must switch on the Multistreaming toggle whenever they're also live on a landscape platform like Twitch or YouTube. It's in your dashboard while you're live, or type /multi on in chat. Not doing it can get your account actioned.
  • With the toggle on, Kick Partner Program earnings for that time are halved. Subscriptions aren't affected.
  • Vertical platforms such as TikTok don't count, so Kick + TikTok needs no toggle.
  • Changing category while live can reset the toggle, so check it after switching.
  • Not a Kick Partner? The toggle is described for partners only; check Kick's current rules for your account.
YouTube
  • Multistreaming is allowed.
  • You need a verified channel with live streaming switched on. The first time, it can take up to 24 hours to be enabled, so do it well before your first stream.
  • Music: YouTube's Content ID is strict, and copyrighted music can block or mute the stream or VOD.
TikTok
  • Not everyone can stream to TikTok from OBS. A stream key generally needs 1,000+ followers, being 18 or over, a clean account and a region that has it. Some report TikTok also wanting mostly gaming content for key access.
  • The stream key changes: get a fresh one before every stream.
  • TikTok is vertical, so it needs its own 9:16 layout (section 5).
  • Only one TikTok LIVE at a time: going live from your phone ends the OBS stream.
4

Setting it up in OBS

1. Install a plugin

Close OBS first. Get Aitum Multistream (from Aitum's site, needs OBS 30 or later) or Multiple RTMP outputs (from the OBS forum's Resources section), run the installer, then open OBS. A new dock appears: if you can't see it, look under Docks.

Only download plugins from their official pages, and keep them up to date: older versions of Multiple RTMP outputs could crash OBS when streaming started twice in quick succession.

2. Set the main stream

Settings → Stream: choose your main platform (normally Twitch) and connect your account or paste its key. This is what OBS's normal Start Streaming button sends.

3. Add an output for each other platform

In the plugin's dock, add a target for each platform, paste its server URL and stream key (below), and:

  • Share the encoder with the main stream where the plugin offers it. It saves a lot of GPU and CPU, and keeps every landscape platform at the same quality (which keeps Twitch's rule happy).
  • Tick "start/stop with OBS streaming" (wording varies), so one press starts everything.
  • Pick the audio track: Track 1 is usually everything. If you use a Twitch VOD track to keep music off Twitch VODs, think about whether other platforms' VODs need the same.

Twitch

  1. OBS Settings → Stream, Service: Twitch.
  2. Connect Account (easiest), or paste the key from Creator Dashboard Settings → Stream.

Keep Twitch as the main stream. Enhanced Broadcasting (and the vertical Dual Format for Twitch mobile viewers) only works there.

Kick

  1. Kick Creator Dashboard → Settings → Stream URL & Key.
  2. Copy the Stream URL (it starts rtmps://) into the server box and the Stream Key into the key box.

Partners: switch on the Multistreaming toggle each time you're also live on Twitch or YouTube.

YouTube

  1. YouTube Studio → Create → Go live → Stream.
  2. Copy the Stream URL (rtmp://a.rtmp.youtube.com/live2) and Stream key.
  3. Turn on Auto-start and Auto-stop so it goes live and ends with OBS.

Set the title and thumbnail in Studio before going live, or use a tool that updates every platform's title at once.

TikTok

  1. On a computer, open TikTok's LIVE Producer (livecenter.tiktok.com/producer, or Go LIVE on tiktok.com).
  2. Set the title and category, then copy the Server URL and Stream Key.
  3. Paste them into your vertical output (section 5). Do this every stream: the key changes.

No key yet? TikTok LIVE Studio works without one, but it's separate software, so it doesn't fit neatly alongside OBS.

4. Going live

  1. Kick Partners: be ready to switch on the Multistreaming toggle (or /multi on) as soon as you're live.
  2. TikTok: paste the new key.
  3. Press Start Streaming once, and give every output a few seconds to connect. Don't press it again, and don't have a Stream Deck key or Streamer.bot action send a second "start" at the same moment.
  4. Check each platform is actually live (open each one on your phone).
5

A vertical layout for TikTok

TikTok is watched on phones held upright, so your landscape stream would be tiny with black bars. Give it its own 9:16 layout:

  1. Install Aitum Vertical (free, from Aitum). It adds a second, upright canvas inside OBS with its own scenes.
  2. Set the vertical canvas to 1080×1920 (or 720×1280 if your PC or upload struggles).
  3. Build vertical scenes: camera at the top, gameplay cropped to the action in the middle, chat or alerts at the bottom. You can reuse the same sources.
  4. Send the vertical canvas to TikTok, using Aitum Vertical's own stream settings or as a vertical target in Aitum Multistream.

Extra load: the vertical layout is a second encode, so it adds GPU work and upload on top of your landscape outputs. The planner above includes it.

6

Chat, alerts and titles everywhere

  • Read every chat in one place: Streamer.bot connects to Twitch, Kick and YouTube. This hub's Combined Chat shows Twitch and Kick together. TikTok chat needs a TikTok-specific tool. Mind Twitch's merged-chat rule if you put it on screen.
  • Alerts from more than one platform: Alerts, Activity Feed, Sub Goal and Goal Bars here handle Twitch and Kick together.
  • Talk to every chat: bots usually send to one platform at a time, so check yours replies on all of them. In Streamer.bot, Twitch and Kick need separate "send message" steps.
  • Titles: set them everywhere before you go live. Some Streamer.bot add-ons update Twitch, Kick and YouTube titles in one go.
  • Raids and shoutouts are per platform: a Twitch raid only moves Twitch viewers.

When it goes wrong

ProblemUsual cause and fix
One platform never goes liveWrong or old stream key (TikTok's changes every stream), a typo in the server URL, or the output isn't set to start with OBS. Re-copy the key and URL; start that output by hand to test.
OBS crashes, or outputs drop, the moment you go liveSomething told OBS to start streaming twice: a Stream Deck key plus a Streamer.bot action, or two presses. Keep one thing in charge of starting, and update the multistream plugin.
Dropped frames (network) on every platformYou're sending more than your upload can carry. Lower the bitrate, drop an output, use a cable instead of Wi-Fi, or switch to a relay.
Dropped frames on one platform onlyThe route to that platform's server is struggling. Try another server for it, or a lower bitrate just for that output.
"Encoding overloaded" or the stream stuttersToo many encodes. Share the main encoder with landscape outputs, use your graphics card's encoder (NVENC, AMF or QuickSync), and drop the vertical to 720×1280.
YouTube shows "waiting for stream"Auto-start is off, or the key is from a different scheduled stream. Turn Auto-start on, or press Go Live in Studio.
Kick earnings lower than expectedThe Multistreaming toggle halves Partner Program earnings while it's on. That's expected when you're also on Twitch or YouTube.
TikTok shows the landscape stream squashed or with black barsThe TikTok output is sending the main canvas. Point it at the vertical canvas instead.
Twitch looks worse than the othersIts output has a lower bitrate or resolution. Match them, ideally by sharing one encoder, since Twitch requires it to be at least as good.
