Set up your OBS scenes the right way, once.

Scenes are the different "screens" your viewers see: starting soon, gameplay, chatting, be right back, ending. Get them right once and every stream is a few clicks. This guide covers the scenes you need, a builder that lists every source in the right order, and the fixes for the problems everyone hits.

The scenes you need

Start with these five. Add more (a Waiting or Respawn scene, a second game, a camera-only scene) only when you find yourself wanting one.

Capturing your game and camera

Game: try these in order

  1. Game Capture (best): set Mode to Capture specific window and pick your game. It only shows the game, never your desktop or notifications.
  2. Black screen? Run OBS as administrator (right-click → Run as administrator; make it permanent in the shortcut's Properties → Compatibility). Toggle Use anti-cheat compatibility hook off and on.
  3. Laptop with two graphics chips? Windows Settings → search "Graphics settings" → add OBS → Options → High performance → Save, then restart OBS.
  4. Still black: use Window Capture with Capture Method Windows 10 (1903 and up). Some anti-cheat games only work this way.
  5. Last resort: Display Capture, which shows your whole monitor. Turn off notifications and close anything private first.

Camera

  • Add a Video Capture Device, then set Resolution/FPS Type to Custom and pick the resolution and frame rate your camera does best (often 1920×1080 or 1280×720 at 30 or 60).
  • Add your camera once. In other scenes use + → Video Capture Device → Add Existing, or copy it and use Paste (Reference). A second "new" camera source will fail with "device in use".
  • Crop with Alt+drag on the edges, or right-click → Filters → Crop/Pad. Add a Chroma Key filter here for a green screen.
4

The overlays trick: set it up once

Make one scene called Overlays and put your alerts, goals, polls and anything else you want everywhere into it. Then add that scene into each of your other scenes: + → Scene → Add Existing → Overlays.

  • Change it once, it changes everywhere. Move your alerts and every scene follows.
  • One copy running, not five. Each browser source uses memory and CPU; a single shared copy keeps OBS lighter, and alerts never fire twice.
  • Keep the Overlays scene at the top of each scene's list so alerts sit in front of everything.
  • The builder above uses this: the shaded row in each scene is the shared Overlays scene.
5

Switching scenes and transitions

  • Hotkeys: Settings → Hotkeys, find each scene and set "Switch to scene". Function keys or a numpad work well.
  • Stream Deck: the OBS actions switch scenes, mute sources and start the stream with one press.
  • Studio Mode (button under Controls) lets you set up the next scene on the left before sending it live. Handy for bigger changes.
  • Transitions: a quick Fade (300 ms) suits most streams. For something branded, a Stinger plays a short video between scenes: it needs a file with a see-through background (WebM or MOV) and a "transition point" when the scene switches behind it.
  • Right-click a scene → Transition Override to give one scene its own transition, like a slower fade into Ending.
6

Audio per scene

  • Your mic is easiest as a global device in Settings → Audio, so it's in every scene. Mute it with a hotkey or Stream Deck key on breaks.
  • Game audio as an Application Audio Capture inside the Gameplay scene: it goes quiet automatically when you switch to BRB.
  • Music for breaks goes in the Starting, BRB and Ending scenes only, so it never plays over gameplay.
  • Discord as its own Application Audio Capture, in the Overlays scene if you want friends heard everywhere, or only in Gameplay.
  • Levels and filters are in the Mic & Audio Guide, including keeping music off your Twitch VODs.
7

Back it up and keep it tidy

  • Export your scenes: Scene Collection → Export saves a small file with every scene and source. Do it whenever you make big changes, and before updating OBS.
  • Export your settings too: Profile → Export saves your stream and output settings.
  • Keep all your images, videos and sounds in one folder (for example Documents\Stream Assets). Scene files only store where things are, so moving them breaks sources. If it happens, OBS's "missing files" window can search a folder and fix them all at once.
  • Name things clearly: "Camera", "Game", "Alerts", not "Video Capture Device 3".
  • Lock sources you've placed (the padlock) so a stray click doesn't move them mid-stream.
